🥁 Drum Kit

A fun and interactive **Drum Kit Web Application** built with HTML, CSS, and JavaScript. Play different drum sounds by clicking the buttons or using your keyboard.

🚀 Live Demo

[Play the Drum Kit](https://ahmadnawaztech.github.io/Drum-kit/)

✨ Features

* 🥁 Interactive drum buttons
* ⌨️ Keyboard support
* 🖱️ Click-to-play functionality
* 🔊 Different sounds for different drum keys
* 📱 Simple and responsive interface
* ⚡ Fast and lightweight
* 🎨 Clean and interactive UI

🎮 How to Use

You can play the drums in two ways:

🖱️ Using the Mouse

Click any of the drum buttons on the screen to play its corresponding sound.

⌨️ Using the Keyboard

Press any of these keys:

text
W   A   S   D   J   K   L


Each key triggers a different drum sound.

🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and layout
* **JavaScript** — Interactivity and sound control
* **HTML Audio** — Playing drum sounds
